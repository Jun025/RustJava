## 2. ★판정 — ⒝ **격차 기반 · `behind ≥ 20`**

> ★**동기 회차는 `git rev-list --count origin/main..upstream/main` 이 «20 이상»일 때 연다.**
> ★**시간(격주·월간)으로 열지 않는다.** ★**그 아래에서는 열지 않는다.**

### ⒜ ★시간 기반(⒜)을 기각한 이유 — 둘 다 실측이다

⑴★**upstream 이 37% 의 주에 커밋 «0»** 이고 버스티하다(p90 7/주) ⇒ 시간 축은 ★**behind 0 인데 회차를 여는 «빈 회차»** 를 만든다.
⑵★**충돌이 포화하므로 «작게 자주»가 총비용을 낮추지 않는다** — 회차 오버헤드는 **고정**이다(티켓 **3건**/회차 ·
게이트② 사이클은 **8회차 중 7회가 1**). ⇒ ★**충돌 총량이 그대로인데 회차 수만 늘면 «총비용이 는다».**

### ⒝ ★사건 기반(⒞)을 기각한 이유

「우리 포크 지점 파일을 upstream 이 건드리면」이 그럴듯해 보이지만 ★**데이터가 안 맞는다**:
S3 의 충돌 ★**델타 +9**(누적 **11** · base S2 착지본 · merge-base `af4f6f8`)는 ★**upstream 의 «신규» 파일**에서 왔고(우리 파일이 아니다),
S8 의 ★**누적 8 · 델타 +8**(base `3fb08a8` · merge-base `ba5797b`)은 ★**전 트리 개명**이었다.
★**[게이트² 정정] 초판은 여기서 두 수를 «맨 수»로 적었다** — 같은 파일 §1 표는 정확히 병기하고 있었으므로 ★**한 파일 안에서 갈렸다**.
⇒ ★**경로 기반 방아쇠는 실제 비용의 대부분을 «놓친다».**

### ⒞ ★정기 축을 두지 않는 것(⒟)을 기각한 이유

★**오늘 «아무것도» 알려 주지 않는다.** behind 는 사람이 생각날 때만 재고, 이 캠페인이 그 상태에서 33까지 갔다.
★그리고 ⒝ 의 포화는 **7~33 구간에서만** 측정됐다 — 33 너머는 ★**미측정**이다.
★**[정정] 「33 은 실제로 아팠던 값」은 여기서도 «지웠다»** — §1⒝ 가 금지한 독법이다. ★**「미측정」 논거는 혼자 선다.**
⇒ ★**미측정 구역으로 걸어 들어가지 않는다.**

### ⒟ ★왜 «20» 인가 — 위아래를 둘 다 적는다

- **더 내리지 않는다**: 충돌이 **7커밋에서 포화**하므로 그보다 자주 받아도 충돌 총량이 안 준다(회차 수만 는다).
- **더 올리지 않는다**: 33 은 **미측정 구역의 입구**다(§5 첫 표의 상한).
  ★★**[정정] 초판의 「실제로 아팠다」는 «지웠다»** — §1⒝ 가 «금지한» 독법(8회차를 격차의 비용으로 읽는 것) 위에 서 있어
  **같은 문서 안의 자기모순**이었다. ★**「미측정」 논거는 혼자 선다.**
- ★★**[명시] 「20」은 «밴드 안에서 «고른» 수»다** — 밴드(하한 **7** 포화 시작 · 상한 **33** 측정 상한)가 실측이고,
  그 안 누적이 `16→17→17→17→19` 로 **평평**해 어디를 골라도 데이터는 같은 말을 한다.
  ⇒ 고른 근거는 「도달 중앙 ≈6주 ↔ 회차 오버헤드 3티켓의 균형」이라는 ★**판단**이고, ★**§5 재측정 조건이 그것을 검증한다.**
  ★**밝히는 것이 논증을 약화시키지 않는다.**
- ★**늦게 알수록 «우리 자산 낡음»이 오래 방치된다** — S8 개명 스윕이 `rust.yml` 크레이트 이름과 경로 4곳을
  낡게 만들었고, 그 여파가 **문서 정정 5회차**로 이어졌다(§4 리니지).
- 실측 도달 시간 **중앙 44일** ⇒ ★**연 6~8회**.

## 4. ★누가 방아쇠를 당기는가 — **기계가 «재고», 사람(총괄)이 «발권한다»**

```sh
git fetch -q upstream && git rev-list --count origin/main..upstream/main   # ★오늘 = 0
```

- ★**재는 자리(권고) = 이 repo 의 «예약 워크플로»**. 선례가 있다 — `rust-audit.yaml` 이 이미 `schedule: cron` 을 쓴다.
  upstream 을 **read-only fetch** 해 그 수를 찍고, 임계 초과 시 **눈에 보이게** 알린다.
  ★**upstream 발신 0**(fetch 는 «읽기»다 — PR·이슈·코멘트·push 아님).
- ★**대안 = 총괄 레인의 `bin/healthcheck` 축**(그 레인에 이미 체크아웃이 있다).
  ★**그것은 `orchestrator` repo 소관이라 이 저장소가 정할 수 없다** ⇒ ★**별건 판정**으로 넘긴다.
- ★★**발권은 «사람(총괄)»이 한다 — 기계가 자동으로 동기 회차를 열지 않는다.**
  이유: 회차마다 **설계 판단**(우리 포크 지점을 유지할지)이 들어가고 S1·S2·S3 에서 **실제로 필요했다**.
- ★**구현은 «별건»이다** — 이 회차는 검사기·크론·워크플로를 **하나도 만들지 않았다**(티켓 non-goal).
