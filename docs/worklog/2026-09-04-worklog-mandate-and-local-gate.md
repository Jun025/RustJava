## #p1 — 잠금을 로컬에서 도는 명령으로

### ★먼저 확인했다 — 「지금 어디서만 도는가」

- **CI 전용**: `.github/workflows/rust.yml:59-63` `worklog_json` job(`ubuntu-latest` 1러너) 한 곳뿐이다.
  `rust_ci` 6셀 매트릭스(`:52-56`)에는 **없다.**
- **로컬 DoD 3명령**(`CLAUDE.md` §Definition of Done · 상세 `AGENTS.md` §Build/Test Commands):
  `cargo fmt --check` · `cargo clippy` · `cargo test`.
- ⇒ ★**틀린 파일은 PR 을 열어야 비로소 빨개진다**(제안이 적은 그대로).

### 처분 — DoD green 줄에 **4번째 명령**으로 붙였다

```diff
-- `cargo fmt --check` · `cargo clippy` · `cargo test` 전부 green(명령 상세 = `AGENTS.md`).
+- `cargo fmt --check` · `cargo clippy` · `cargo test` · `python3 scripts/check-worklog-json.py`
+  전부 green(명령 상세 = `AGENTS.md`).
```

### ★★`cargo test` «안»으로 넣지 않은 이유 — 오탐 0 이 절대 조건이라서

두 경로를 다 검토하고 **둘 다 기각**했다:

| 경로 | 기각 사유 |
|---|---|
| `serde_json` dev-dep + Rust 테스트(제안 ⑴) | `serde_json` 은 ★**`Cargo.lock` 에 없다**(실측) ⇒ 새 의존성 + **6셀 매트릭스** 빌드 시간. ★스크립트 자신의 docstring 이 이미 같은 이유로 기각한 길이다. Non-goal 「새 도구 0」과도 어긋난다. |
| Rust 테스트가 `python3` 를 shell-out | ★**오탐이 난다** — python3 없는 머신에서 `cargo test` 가 **red** 가 된다. 그것은 「기존 로컬 검사가 새로 red 가 되지 않는다」는 절대 조건 위반이다. |

⇒ ★**3명령은 «한 글자도» 안 건드렸다.** 그래서 기존 검사의 오탐 위험은 **구조적으로 0** 이다
(새 실패 모드는 4번째 명령 자신에만 붙는다).

**재컴파일이 필요한 회차(60.2s) 기준 +0.17%** · ★**완전 캐시 회차(9.36s) 기준 +1.1%**.
